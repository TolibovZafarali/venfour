# Missouri guide migration and source review

Sources checked: **September 26, 2026** (America/Chicago).

The approved Missouri guide now uses the same typed content module and shared
presentation as the other jurisdictions. Its section order, practical checklist,
sample message, service terms, and two calls to action remain intact.

| Source | Reviewed location and retained qualification |
| --- | --- |
| [Auto insurance FAQs](https://insurance.mo.gov/consumer-faqs/auto-insurance-faqs) | Disputed total-loss value; book values, dealer quotes, and available comparable vehicles. |
| [Automobile claims regulation](https://s1.sos.mo.gov/cmsimages/adrules/csr/current/20csr/20c100-1.pdf#page=4) | 20 CSR 100-1.050(2)(E), PDF page 4, printed page 5. Itemized, appropriate reductions and claim-file retention remain distinct from the customer's practical request for an explanation. |
| [Salvage definition](https://revisor.mo.gov/main/OneSection.aspx?section=301.010) | Subdivision (55). Exceeds 80%, model-year limitation, excluded repair costs, and alternative classifications; not a settlement formula. |
| [Replacement tax allowance](https://dor.mo.gov/faq/motor-vehicle/titling-registration.html#q13) | The actual `q13` HTML target was confirmed. Replacement timing, common owner, deductible, and notarized or agent-certified statement requirements remain in the guide. |
| [Complaint guidance](https://insurance.mo.gov/consumer-complaints/insurance-complaints) | Communication records, complaint review, hotline, and limits on determining claim value. |
| [Policy-reading guidance](https://insurance.mo.gov/understanding-your-automobile-insurance-policy) | Policy terms and endorsements; appraisal wording stays conditional. The unavailable sample appraisal-policy PDF is not linked. |

All six destinations and their supporting content were reviewed again for this
migration. Citations sit beside the supported paragraphs. The content module
records claim summaries, applicability, locators, and the fixed review date.

The shared commercial copy was reconciled with the repository refund-policy page:
one-time $199 price; automatic refund when the completed review supports no
dispute; separate request-based protection for an eligible final verified
vehicle-value increase under $1,000, with process, documentation, and deadline
conditions. This migration changes no payment or refund logic.

The consolidated verification report records rendering, source-reference,
metadata, accessibility, viewport, and build results.
